# FriendsHub

موقع ASP.NET Core MVC (.NET 8) فيه:

1. **شات جماعي لايف** (SignalR) — `/Chat`
   - رسائل نصية عادية
   - إيموجيز (زرار 😀)
   - ستيكرات كبيرة (زرار 🎉)
   - إرسال صور (زرار 🖼️)
   - تسجيل صوتي من المتصفح وبعته كرسالة (زرار 🎤 — دوس تاني عشان توقف وتبعت)
2. **تقسيم فرق عشوائي** من قائمة أسماء — `/Teams`
3. **بوستات وستوريز** زي انستجرام — `/Posts`
4. **ألعاب**:
   - **إكس أو أونلاين حقيقي** — `/Games/TicTacToe`: تعمل تحدي، حد تاني أونلاين يقبله، وأي حد يقدر "يتفرج" على المباراة لايف وهي شغالة. كله بيتحدث لحظيًا (SignalR).
   - **لعبة الذاكرة** (محلية) — `/Games/Memory`
5. **غرفة مشاهدة جماعية (Watch Party)** — `/Watch`
   - تلصق رابط فيديو يوتيوب وتعمل غرفة، وبتبقى ظاهرة لحظيًا لكل الأونلاين
   - أي حد ينضم للغرفة، لكن المضيف (اللي عمل الغرفة) بس هو اللي يشغل/يوقف/يقدم الفيديو، والباقي بيتحرك معاه أوتوماتيك (Sync لحظي عن طريق YouTube IFrame API + SignalR)
   - شات جانبي لايف جنب الفيديو للتعليقات وقت المشاهدة (مش محفوظ في قاعدة البيانات، بس شغال طول ما الغرفة شغالة)
   - المضيف يقدر يغيّر الفيديو في أي وقت من نفس الصفحة
6. **تسجيل دخول منفصل**: صفحة للأدمن (`/Account/AdminLogin`) وصفحة للمستخدمين العاديين (`/Account/Login` + `/Account/Register`)

## المتطلبات
- .NET 8 SDK: https://dotnet.microsoft.com/download

## طريقة التشغيل

```bash
cd FriendsHub
dotnet restore
dotnet run
```

هيفتح على `https://localhost:5001` (أو البورت اللي هيظهر في التيرمينال). قاعدة البيانات (SQLite) بتتعمل تلقائي أول مرة، مفيش migrations مطلوبة.

> ملاحظة: التسجيل الصوتي (المايك) بيشتغل بس على `https://localhost` أو دومين حقيقي بشهادة SSL — المتصفحات بترفض تستخدم المايك على HTTP عادي.

## حساب الأدمن الافتراضي
```
Username: admin
Password: Admin@123
```
من `/Account/AdminLogin`. تقدر تغيّر البيانات دي في `appsettings.json` قبل أول تشغيل. المستخدمين العاديين بيعملوا حساب من "اعمل حساب" وبيدخلوا من `/Account/Login`.

## إزاي شغالة لعبة إكس أو الأونلاين
- في `/Games/TicTacToe` تقدر تعمل "تحدي جديد" — بيتحط في قائمة "تحديات مفتوحة" ظاهرة لأي حد أونلاين لحظيًا.
- أي حد تاني (غير صاحب التحدي) يقدر يدوس "انضم كخصم" فتبدأ اللعبة بينكم في غرفة خاصة (رابط فريد لكل غرفة).
- أي حد ثالث يفتح صفحة الغرفة (أو يدوس "اتفرج" من قائمة "مباريات شغالة دلوقتي") بيتفرج لايف من غير ما يقدر يلعب.
- بعد ما اللعبة تخلص، اللاعبين (مش المتفرجين) يقدروا يدوسوا "لعبة تانية 🔁" يبدأوا من الأول في نفس الغرفة.
- حالة الغرف دي محفوظة في الذاكرة (مش في قاعدة البيانات) — يعني لو عملت `dotnet run` تاني كل الغرف بترجع فاضية، وده طبيعي لنوعية اللعبة دي.

## حاجات معروف إنها بسيطة/ناقصة دلوقتي (ممكن تتطور بعدين)
- عداد المتفرجين مبيقلش لما حد يسيب صفحة الغرفة (بيزيد بس).
- لو لاعب قفل المتصفح فجأة نص اللعبة، مفيش رسالة "الخصم قطع الاتصال" (اللعبة بتفضل معلقة).
- الستيكرات دلوقتي إيموجيز كبيرة، مش صور رسمية — سهل تستبدلها بصور حقيقية في `wwwroot/js/chat.js`.
- الشات كله في غرفة واحدة عامة، مفيش شاتات خاصة/جروبات منفصلة.
- غرفة المشاهدة الجماعية بتشتغل مع فيديوهات يوتيوب بس (عن طريق YouTube IFrame API). لازم يكون الفيديو مسموح تشغيله جوه iframe (بعض الفيديوهات بتمنع الـ embedding من صاحبها).
- لو المضيف قفل المتصفح، الغرفة بتفضل موجودة بس محدش هيتحكم فيها تاني.

قولّي أي حاجة من دول عايز نطورها، أو نكمل باقي الألعاب اللي طلبتها (تقسيم الفرق لايف + عداد، عجلة الحظ، لعبة القاتل).
